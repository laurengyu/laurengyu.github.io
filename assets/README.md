# assets/

- **`cover.jpg`**: drop the round header logo here (a square image works best; it's cropped to a 56px circle). The header loads it from `/assets/cover.jpg`. Until you add it, a beige circle shows instead.
- `images/`: images used inside posts (e.g. `images/damage.jpg`, downloaded from the original Tumblr post).
- `main.scss`: entry stylesheet (Minima loads it as `/assets/main.css`); the actual skin lives in `/_sass/corner-shelf.scss`.
